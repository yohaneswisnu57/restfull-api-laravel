Interactive API Reference

Explore and test all authentication endpoints directly from this page. No external tools needed — just register or login, grab your token, and start making requests.

1
Call Register or Login to get an access_token
2
Click Authorize 🔓 below and enter: Bearer your_token
3
Try any 🔒 protected endpoint — it will use your token automatically
Base URL
http://localhost:8000/api
💡
How to authenticate: After a successful Login or Register, copy the access_token from the response. Then click the Authorize button in the Swagger UI below, and enter your token as Bearer <your_token>. All protected endpoints (marked with 🔒) will automatically include your token.
